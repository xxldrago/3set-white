## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `/admin/**` (RSC + RSC payload fetch) | Untrusted request claims a session cookie; role must be resolved server-side from `admin_users` |
| `ADMIN_TELEGRAM_IDS` env → bootstrap | Server-only bootstrap grant; must not become a standing elevation source |
| `lib/admin-auth` → `prisma.adminUser` | Role reads/writes are server-only; the client never supplies a role |
