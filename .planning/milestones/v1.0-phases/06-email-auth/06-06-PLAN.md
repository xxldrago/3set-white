## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-06-01 | Spoofing | consume route | high | mitigate | Claim-cookie bind (HMAC of token, httpOnly) so only the issuing browser consumes; status endpoint never mints |
| T-06-06-02 | Tampering | token replay | high | mitigate | Atomic single-use consume + 10-min TTL; bind idempotent per telegramId, different id rejected |
| T-06-06-03 | Information Disclosure | status oracle | medium | mitigate | Unknown and expired tokens both report expired; no user data in request/status responses |
| T-06-06-04 | Denial of Service | request issuance | medium | mitigate | Per-IP throttle (20/hour) with server-computed 429, same discipline as D-84 |
| T-06-06-05 | Spoofing | bot start payload | medium | mitigate | Token shape-gated (login_ + 48 hex); bind of unknown/expired token replies keyed invalid, no session effect |
| T-06-06-SC | Tampering | npm installs | high | mitigate | No new dependencies in this plan; no install step |
