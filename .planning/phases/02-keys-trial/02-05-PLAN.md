Render: subscription URL with a copy button (`key.copy`→`key.copied`), `components/QrSvg` (server-produced SVG; caption `key.qrCaption`), traffic (`key.trafficUsed`/`key.trafficOf`, humanized to GB with one decimal ≥1 GB, MB below, `tabular-nums`), expiry (`key.expires` with `DD.MM.YYYY`), and a `t("key.guidesCta")` deep-link to `/guides` (TRIAL-03). ## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser/bot to BFF | the session cookie is the only identity source; `id` is untrusted |
| BFF to ARTEMIDA | subscription links (credential-bearing) cross here |
| server to rendered HTML | trusted local SVG is injected inline |
