## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser to BFF | the session cookie is the only identity source; `id`/`token` are untrusted |
| BFF to ARTEMIDA | irreversible device mutations cross here |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-21 | Information disclosure / Tampering | IDOR on device routes | high | mitigate | Ownership join on `(userId, keyId)` before any provider call; non-owned key → 404; device-route tests prove no mutation for a non-owned key |
| T-02-22 | Repudiation | unconfirmed destructive action | high | mitigate | D-32 inline `ConfirmPanel`; no request until the explicit second tap; Escape/Cancel are no-ops; no `window.confirm` |
| T-02-23 | Input validation | `token`/`id` path params | medium | mitigate | zod-validate both segments before any provider call; async `params` awaited |
| T-02-24 | Denial of service | rapid repeated mutations | low | accept | Irreversible actions are user-initiated and rate-limited upstream by ARTEMIDA's adaptive limiter; v1 leaves this to the provider |
| T-02-SC | Tampering | npm installs | high | mitigate | No new packages in this plan |
</threat_model>
