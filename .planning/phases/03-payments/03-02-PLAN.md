<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → POST /api/orders | Untrusted body; session supplies the user identity |
| Platega (public internet) → POST /api/platega/callback | Untrusted, anonymous; authenticated only by X-MerchantId/X-Secret headers |
| callback handler → Platega API (re-query) | Trusted server-to-server; the source of truth for status/amount |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-forge | Spoofing | /api/platega/callback | high | mitigate | Timing-safe X-MerchantId/X-Secret compare BEFORE body parse; mandatory re-query; CONFIRMED-only; amount/currency equality — a forged body alone mints nothing |
| T-03-amount | Tampering | order amount vs callback | high | mitigate | Server re-quotes via GET /pricing before persisting; callback compares re-queried amount+currency to the stored order (D-35); mismatch → no issue + alert |
| T-03-dup | Tampering | duplicate CONFIRMED | high | mitigate | `updateMany({where:{id,status:'pending'}})` atomic claim → count===1 only winner; unique `(orderId,type)` outbox upsert |
| T-03-idor | Information Disclosure | order status/load | medium | mitigate | `loadOrderForUser` joins `user:{telegramId}`; non-owned === missing |
| T-03-secret | Information Disclosure | PLATEGA_* env | high | mitigate | Secrets only in lib/env.ts; no NEXT_PUBLIC; routes log codes only, never provider ids/text |
| T-03-create-retry | Tampering | createTransaction | medium | mitigate | Never auto-retry create; tests assert call-count 1 |
| T-03-SC | Tampering | npm/pip/cargo installs | high | mitigate | Embargos unofficial Platega SDKs (D-37); no new packages this phase |
</threat_model>
