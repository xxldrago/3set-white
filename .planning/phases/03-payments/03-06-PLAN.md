## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /api/orders, /api/pricing | Client sends only kind/days/devices/keyId; server re-quotes and re-checks ownership |
| browser → Platega hosted page | Redirect only; we never render card fields or credentials |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|------|-----------|----------|-------------|-----------------|
| T-03-amount-tamper | Tampering | client price | high | mitigate | UI never sends a price; PayCta sends only kind/days/devices; server re-quotes |
| T-03-raw-leak | Information Disclosure | rendered surfaces | medium | mitigate | Every string via t(); chip/panel map statuses; no provider id in DOM tests |
| T-03-trial-ui | Tampering | SubscriptionCard | medium | mitigate | Trial keys render no renew/upgrade in DOM; server also rejects (defense in depth) |
| T-03-double-submit | Tampering | PayCta | medium | mitigate | In-flight lock disables the CTA during order creation |
| T-03-url-state | Information Disclosure | Platega url | low | accept | URL is in component scope only for the redirect; never persisted or logged |
| T-03-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new packages; no shadcn (UI-SPEC registry gate N/A) |
</threat_model>
