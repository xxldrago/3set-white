|----------|-------------|

| stats page → ARTEMIDA API | Server-only provider read; cached; must degrade, never leak provider text |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-09 | Tampering | broadcast body / Bot API parse | high | mitigate | Plain-text `sendMessage` (NO parse_mode); zod trim min 1 max 4000; administrator-only |
| T-05-10 | Denial of Service | broadcast retry storm on dead chats | high | mitigate | 403/400 terminal `failed` (never reschedule); 429/5xx backoff; per-recipient UNIQUE dedupe key (Pitfall 5) |
| T-05-11 | Information Disclosure | broadcast wrong-chat send | high | mitigate | Resolve the owning `User.chatId ?? telegramId` server-side; never a caller-supplied chat (mirrors T-04-10) |

| T-05-13 | Information Disclosure | ARTEMIDA read fan-out / provider leakage | medium | mitigate | Single cached `getBalance`+`listKeys`; degrade to `—`/`unknown`; no provider text/code/Retry-After rendered (D-19/D-24) |
| T-05-14 | Elevation of Privilege | broadcast route | high | mitigate | `requireRole("administrator")`; 404 on any other role |
