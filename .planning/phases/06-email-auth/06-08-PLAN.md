<objective>
Repair the 06-05 regression that broke every Telegram Login Widget callback (AUTH-03 link UI is non-functional; AUTH-06 button is positioned but dead). Telegram parses `data-onauth` as a function BODY (`__parseFunction` -> `eval('(function(user){<value>})')`); the current value `window.telegram-login-<bot>-<rand>OnAuth(user)` contains hyphens in a dot path, which parse as subtraction and throw `ReferenceError: login is not defined`. Replace it with an identifier-only global callback referenced directly, without changing the widget's in-flow containment (AUTH-06 layout stays fixed).

Purpose: Restore Telegram login and Account link so the phase goal "может связать Telegram-аккаунт" is achievable in a browser.
Output: A pure, testable callback-name builder, a corrected injector, dead-global cleanup, and a regression test that evaluates the emitted attribute exactly the way Telegram does.
</objective>
