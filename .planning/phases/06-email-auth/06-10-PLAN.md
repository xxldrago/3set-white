<objective>
Close CR-02: every IP-derived rate limit trusts the first `X-Forwarded-For` entry, which nginx prepends the client-supplied value to, so an attacker rotates a spoofed header to defeat both the login brute-force lock and the 20/hour bot-token issuance throttle. Read a trusted hop (`X-Real-IP`, else the last XFF entry), stop nginx from concatenating client values, and add a per-email-only attempt counter so the account lock cannot be reset by changing IP.

Purpose: make D-84 backoff/lock and the T-06-06-04 throttle actually enforceable.
Output: a shared client-IP helper, an IP-independent per-email lock, route wiring, hardened nginx, and unit tests.
</objective>
