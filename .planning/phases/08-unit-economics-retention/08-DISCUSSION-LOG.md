## LTV: база и формула

| Option | Description | Selected |
|--------|-------------|----------|
| Все платящие, простое среднее | Σ кэша за всё время ÷ все пользователи с ≥1 paid-заказом; активные помечаются как недоамортизированные | ✓ |
| Только завершённые (churned) | Считаем только по пользователям без активной подписки — честнее «lifetime», но выборка меньше | |
| Обе цифры рядом | LTV по всем платящим и отдельно LTV завершённых | |

**User's choice:** Все платящие, простое среднее
**Notes:** База согласована с логикой ARPPU; активные плательщики признаны недоамортизированными.

| Option | Description | Selected |
|--------|-------------|----------|
| Logo churn по подпискам | Месячная доля истёкших и не продлённых ключей | ✓ |
| Revenue churn (MRR) | Доля потерянного MRR за месяц | |
| Оба, переключатель | Два прогноза LTV gross с подписью основания | |

**User's choice:** Logo churn по подпискам
**Notes:** Парный к ARPPU на платящего, стабильнее на малых числах.

| Option | Description | Selected |
|--------|-------------|----------|
| Только окно полного покрытия | Заказы с `providerCost ≠ null`; знаменатель — платящие в этом же окне | ✓ |
| Всё время, null пропускаем | Cumulative cash − известный providerCost, null-затраты не вычитаются | |
| Строго «—» до 100% | Net LTV только когда providerCost известен для всех заказов за всё время | |

**User's choice:** Только окно полного покрытия
**Notes:** Подпись «с даты внедрения себестоимости»; сравнение с gross только рядом с разными подписями окон.

| Option | Description | Selected |
|--------|-------------|----------|
| Нет, фиксированные окна | Исторический LTV за всё время; churn для прогноза — последние 30 MSK дней | ✓ |
| Churn за выбранный период | При `?period=7` прогноз считается по 7-дневному churn | |
| LTV за выбранный период | Cumulative revenue ограничивается окном | |

**User's choice:** Нет, фиксированные окна
**Notes:** Период страницы на LTV не влияет, окна подписаны.

## Renewal / churn

| Option | Description | Selected |
|--------|-------------|----------|
| 7 дней | Стандартное окно продления без потери ключа | ✓ |
| 3 дня | Жёстче и быстрее показывает отток | |
| Настраиваемый (Setting) | Значение меняется без деплоя | |

**User's choice:** 7 дней
**Notes:** Сглаживает выходные и задержки оплаты.

| Option | Description | Selected |
|--------|-------------|----------|
| Реконструкция по цепочке заказов | Термин ключа = `paidAt + days`; конец покрытия в периоде | ✓ |
| Текущий `KeyCache.expiresAt` | Проще, но теряет прошлые истечения | |
| Считать по `daily_metrics` | Быстро, но знаменатель — оценка | |

**User's choice:** Реконструкция по цепочке заказов
**Notes:** История пересчитывается за любой период и не зависит от текущего состояния KeyCache.

| Option | Description | Selected |
|--------|-------------|----------|
| MRR, месячный эквивалент | Потерянный MRR по непродлённым ключам | ✓ |
| Кэш фактического периода | Σ кэша по непродлённым ключам | |
| Обе колонки | MRR churn + cash churn рядом | |

**User's choice:** MRR, месячный эквивалент
**Notes:** Согласовано с ANL-01/02 и не зависит от длины тарифа.

| Option | Description | Selected |
|--------|-------------|----------|
| Только платные; бонус = удержание | Trial исключён, upgrade не продление, бонусное продление удерживает ключ | ✓ |
| Только платные; бонус = отток | Продление без денег не защищает от logo churn | |
| Включая trial | Trial входит в знаменатель | |

**User's choice:** Только платные; бонус = удержание
**Notes:** Бонусное продление не добавляет денег в revenue churn, но подписка считается живой.

## Burn-rate и runway

| Option | Description | Selected |
|--------|-------------|----------|
| Σ providerCost за 30 дней ÷ 30 | Истинный расход провайдера, не искажается пополнениями | ✓ |
| По падению баланса между снапшотами | Буквально по ANL-14, но пополнения ломают знак | |
| Комбинированно | providerCost при полном покрытии, иначе дельта баланса | |

**User's choice:** Σ providerCost за 30 дней ÷ 30
**Notes:** При неполном покрытии — «—» с флагом.

| Option | Description | Selected |
|--------|-------------|----------|
| Живой GET /balance | Текущий баланс на момент открытия страницы | ✓ |
| Последний снапшот | Без вызова API, но отстаёт до суток | |
| Средний за 7 дней | Сглаживает пополнения | |

**User's choice:** Живой GET /balance
**Notes:** Снапшоты остаются только историей.

| Option | Description | Selected |
|--------|-------------|----------|
| «—» + флаг покрытия | burn ≤ 0 → «—»; <7 дней или покрытие <100% → «—» | ✓ |
| «∞» и экстраполяция | Метрика всегда есть, но выглядит точнее, чем есть | |
| Fallback на дельту баланса | Два разных смысла в одном поле | |

**User's choice:** «—» + флаг покрытия
**Notes:** Честное отсутствие данных вместо оценки.

| Option | Description | Selected |
|--------|-------------|----------|
| Оставить 1/сутки + живой баланс | Cron пишет снапшот за вчера; runway берёт живой баланс | ✓ |
| Добавить снапшот за сегодня | История плотнее, нужна отдельная обработка конфликтов | |
| Ручное обновление в админке | Кнопка с записью снапшота | |

**User's choice:** Оставить 1/сутки + живой баланс
**Notes:** Схема и cron не меняются.
