## Когортная база и удержание

| Option | Description | Selected |
|--------|-------------|----------|
| Покрытие пересекает месяц (рекомендуется) | ≥1 платный ключ, покрытие (paidAt + days) пересекает календарный месяц M+N; trial исключён | ✓ |
| Активен на 1-е число месяца | Ключ активен на первый день месяца M+N | |
| cash всех заказов когорты (рекомендуется) | Σ(finalAmount − balanceUsed) по оплаченным заказам когорты в месяце M+N (включая renew/upgrade); деноминатор = cash первого платного месяца | ✓ |
| Только new-заказы | Исключить renew/upgrade из числителя | |
| finalAmount вместо cash | Использовать полную сумму заказа | |
| 12 когорт × 12 смещений (рекомендуется) | Последние 12 месяцев × до 12 относительных месяцев | ✓ |
| 6 × 6 | Компактно | |
| 24 × 12 | Два года когорт | |
| Разрыв остаётся пустым, когорта не меняется (рекомендуется) | Удержание показывает только месяцы с активным покрытием; payer cohort фиксируется по первому платному месяцу | ✓ |
| Переносить в новую когорту | При возврате после >X месяцев — новый payer cohort | |

**User's choice:** Все рекомендованные варианты (покрытие пересекает месяц; cash всех заказов когорты; 12×12; разрыв остаётся пустым).
**Notes:** Консистентно с Phase 7 (cashOf) и Phase 8 (grace/retention по покрытию).

## Канал привлечения

| Option | Description | Selected |
|--------|-------------|----------|
| User-level: referral > promo > organic (рекомендуется) | referral если referredById != null; иначе promo если pendingPromo или любой оплаченный заказ с promoCode; иначе organic | ✓ |
| Order-level: по первому оплаченному заказу | Канал = promoCode первого paid-заказа, иначе referral, иначе organic | |
| Реферал главнее (рекомендуется) | referredById != null → referral, промокод игнорируется | ✓ |
| Промокод главнее | promoCode != null → promo, даже при реферале | |
| Отдельный канал «referral+promo» | Четвёртая категория для смешанных случаев | |
| Нет, вычислять на лету (рекомендуется) | Канал из существующих полей, без миграции | ✓ |
| Да, добавить User.acquisitionChannel | Новая колонка + backfill | |
| Нет, поддомен = referral (рекомендуется) | Поддомен пиннится как referral, три канала: referral/promo/organic | ✓ |
| Да, отдельный канал «subdomain» | Четвёртый канал | |

**User's choice:** Все рекомендованные варианты.
**Notes:** Без миграции; поддомен не выделяется отдельным каналом.
