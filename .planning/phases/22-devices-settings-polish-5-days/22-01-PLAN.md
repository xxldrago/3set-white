| Boundary | Description |
|----------|-------------|
| client → /api/mobile/devices | untrusted JWT; keyId must never arrive from the client |
| client → /api/mobile/devices/{token} | opaque token in path; ownership and length bound enforced server-side |
| server → ARTEMIDA devices API | provider calls only from the BFF; stable error codes cross back |
| Flutter deferred-delete timer → BFF | client-side cancellation window; no provider call before it elapses |
| provider → logs/UI | only stable codes and Russian notices; no token, link or provider text |
