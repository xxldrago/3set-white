03 · импорт ключа

Шаг 3. Импортируйте ключ и подключитесь

Откройте страницу подписки в браузере телефона и нажмите «Импорт» — ключ автоматически скопируется в буфер и будет добавлен в клиент. Либо вставьте URL вручную.

03

Откройте страницу подписки в браузере

Зайдите в личный кабинет на panel.3set.online со своего Android-устройства. На странице подписки будет кнопка «Импорт» — нажмите её, и ключ автоматически скопируется в буфер обмена.

04

Нажмите «Импорт» в клиенте или добавьте URL

В INCY или Happ откройте меню «Профили» → «Импорт из буфера». Если ключ не скопировался автоматически — добавьте URL vless://… вручную через пункт «Добавить вручную».

ИМПОРТ ИЗ БУФЕРА СКАНИРОВАТЬ QR ВСТАВИТЬ URL
05

Разрешите VPN-подключение

При первом подключении Android запросит разрешение на создание VPN-профиля. Нажмите «ОК» или «Разрешить» — это стандартная системная процедура, без неё туннель не поднимется. Подтверждение запрашивается один раз.

⚠ БЕЗОПАСНОСТЬ APK

Устанавливайте APK только из официального источника

Если клиента нет в Google Play — скачивайте APK строго по ссылке, указанной на странице подписки. Сторонние зеркала, форумы и «бесплатные версии» — частый источник вредоносных модификаций.

  • Сверяйте SHA-256 хеш файла с указанным на странице
  • Не устанавливайте APK из Telegram-чатов и форумов
  • Приоритет — всегда Google Play или официальный сайт клиента
✓ СТАБИЛЬНОСТЬ В ФОНЕ

Отключите экономию батареи для клиента

Android агрессивно «убивает» фоновые приложения для экономии заряда. Если VPN-соединение обрывается, когда телефон в кармане или экране выключен — дело именно в этом.

  • Настройки → Приложения → INCY/Happ → Батарея → «Без ограничений»
  • Отключите «Адаптивную батарею» для клиента
  • В MIUI/EMUI добавьте приложение в «Автозагрузку»
troubleshooting · фон

Если соединение обрывается в фоне

Производители Android-смартфонов добавляют собственные оптимизаторы батареи, которые «замораживают» VPN-клиенты. Ниже — универсальный алгоритм решения проблемы.

ОПТИМИЗАЦИЯ БАТАРЕИВЫКЛЮЧЕНА ДЛЯ КЛИЕНТА
01

Чистый Android (Pixel, Motorola)

Настройки → Приложения → INCY / Happ → Батарея → выберите «Без ограничений».

02

Xiaomi / Redmi / POCO (MIUI, HyperOS)

Настройки → Приложения → Все приложения → INCY → Экономия батареи → «Нет ограничений». Плюс добавьте клиент в автозагрузку.

03

Samsung (One UI)

Настройки → Обслуживание устройства → Батарея → Ограничения в фоне → INCY/Happ → уберите из «Глубокого сна».

04

Huawei / Honor (EMUI, MagicOS)

Настройки → Батарея → Запуск приложений → INCY → отключите все три тумблера: «Автозапуск», «Косвенный запуск», «Работа в фоне».

Частые вопросы по настройке на Android

Для большинства пользователей рекомендуем INCY: у него чище интерфейс, быстрее импорт и стабильнее работа на Android 10+. Happ подойдёт, если у вас старое устройство или важна минимальная нагрузка на батарею.

Это стандартная системная процедура Android: любое приложение, создающее VPN-туннель, обязано получить явное разрешение пользователя. Без этого система просто не поднимет соединение. Подтверждение запрашивается один раз.

Да, но только если APK взят строго с официальной страницы подписки или сайта разработчика клиента. Сторонние источники — частый источник вредоносных модификаций. Всегда сверяйте SHA-256 хеш файла.

Это работа системного оптимизатора батареи. Зайдите в Настройки → Приложения → INCY/Happ → Батарея → выберите «Без ограничений». На Xiaomi/Huawei/Samsung дополнительно отключите «адаптивную батарею» для клиента и добавьте его в автозагрузку.

Да, но для Android TV (и приставок) удобнее настроить VPN на роутере — тогда все устройства в сети, включая телевизор, пойдут через туннель автоматически. Отдельная инструкция есть на странице /router/.

В клиенте INCY/Happ откройте список профилей и выберите нужный сервер. Если у вас тариф с авто-ротацией — клиент сам переключится на ближайший рабочий сервер при обрыве связи.
