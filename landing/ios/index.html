01

Откройте Safari

Запустите именно Safari — не Chrome, не Яндекс.Браузер. Только Safari умеет корректно передавать VPN-конфигурацию в приложение.

02

Зайдите на dash.3set.online

Введите адрес личной страницы подписки. Авторизуйтесь, если потребуется — ключ и кнопка импорта будут на этой странице.

03

Установите клиент из App Store

На странице подписки выберите INCY или Happ — откроется ссылка на App Store. Установите приложение. После установки вернитесь в Safari.

04

Нажмите «Добавить в приложение»

На странице подписки нажмите кнопку добавления. iOS покажет системное окно «Открыть INCY?» — подтвердите. Ключ автоматически импортируется в клиент.

04 · подключение

Шаг 4. Разрешите VPN и включите соединение

После импорта ключа осталось обновить профиль в клиенте, выбрать сервер и разрешить создание VPN-конфигурации — iOS покажет системное окно, это нормально.

05

Разрешите добавление VPN-конфигурации

После нажатия «Добавить в приложение» iOS покажет системное окно: «INCY хочет добавить VPN-конфигурации». Нажмите «Разрешить» — это стандартная процедура, без неё туннель не поднимется. Потребуется Face ID / Touch ID / пароль.

SETTINGS → VPN FACE ID / TOUCH ID ONE-TIME APPROVAL
06

Обновите профиль и выберите сервер

В клиенте INCY или Happ откройте список профилей и нажмите «Обновить» — подтянутся актуальные серверы. Выберите ближайший (Финляндия, Германия, Нидерланды дают минимальный пинг из России).

⚠ ТОЛЬКО SAFARI

Импорт подписки работает только через Safari

iOS ограничивает возможность других браузеров передавать конфигурации в приложения. Если вы откроете страницу подписки в Chrome или Яндекс.Браузере — кнопка «Добавить в приложение» не сработает.

  • Откройте dash.3set.online именно в Safari
  • Не используйте «режим инкогито» — он может блокировать deep-link
  • Если кнопка не реагирует — очистите кеш Safari
ℹ СИСТЕМНОЕ ОКНО

«Разрешить добавление VPN-конфигурации» — это нормально

При первом подключении iOS показывает системное окно с запросом разрешения. Это стандартная процедура Apple, без неё VPN-туннель не поднимется. Подтверждение запрашивается один раз.

  • Потребуется Face ID / Touch ID / пароль устройства
  • После подтверждения окно больше не появится
  • Разрешение можно отозвать в Настройки → VPN
✓ ОБНОВЛЕНИЕ ПРОФИЛЯ

Обновляйте профиль при проблемах с подключением

Если сервер перестал отвечать или ключ устарел — нажмите «Обновить» в клиенте. Подтянутся актуальные серверы и конфигурации. Это заменяет ручную переустановку ключа.

  • В INCY: меню профиля → «Обновить»
  • В Happ: настройки подписки → «Reload»
  • Обновление занимает 2–3 секунды
