03 · установка

Шаг 3. Установите клиент

INCY и Happ устанавливаются из App Store одним кликом. V2rayU — через официальный релиз: скачайте .dmg, перетащите в Applications, разрешите запуск в Системных настройках.

03

App Store или официальный релиз

Для INCY и Happ достаточно нажать «Установить» в App Store — приложение появится в Launchpad. Для V2rayU откройте скачанный .dmg, перетащите иконку в папку Applications. При первом запуске macOS может попросить разрешение: «Системные настройки → Конфиденциальность и безопасность → Разрешить».

APP STORE · ОДИН КЛИК .DMG → APPLICATIONS GATEKEEPER APPROVAL
04 · импорт и разрешение

Шаг 4. Импортируйте подписку и разрешите расширение

На личной странице подписки нажмите кнопку добавления — ключ скопируется в буфер или откроется deep-link в клиент. После этого macOS запросит разрешение на установку системного VPN-расширения.

04

Импортируйте подписку

На личной странице подписки нажмите «Добавить в приложение» — клиент откроется автоматически и импортирует ключ. Если deep-link не сработал — скопируйте URL vless://… вручную и вставьте в клиент через меню «Импорт из буфера».

DEEP-LINK · АВТОИМПОРТ КОПИРОВАТЬ URL ИМПОРТ ИЗ БУФЕРА
05

Разрешите системное VPN-расширение

При первом подключении macOS покажет системное окно: «INCY хочет добавить VPN-конфигурации». Нажмите «Разрешить» — потребуется пароль администратора или Touch ID. Это стандартная процедура Apple, без неё VPN-туннель не поднимется. Разрешение запрашивается один раз.

SYSTEM EXTENSION TOUCH ID / ПАРОЛЬ ONE-TIME APPROVAL
06

Обновите профиль и включите TUN/VPN

В клиенте откройте список профилей и нажмите «Обновить» — подтянутся актуальные серверы. Выберите ближайший (Финляндия, Германия, Нидерланды дают минимальный пинг из России). Включите TUN-режим (или «Full Tunnel») — он пропускает через VPN весь трафик, а не только браузер. Нажмите «Connect».

Apple Silicon: iPhone-приложения на Mac

На MacBook с чипами M1/M2/M3/M4 можно запускать многие iPhone-приложения напрямую — включая мобильные версии INCY и Happ. Но нативная macOS-версия обычно удобнее.

01

iPhone-приложения на Mac

Если разработчик не запретил — мобильный INCY или Happ можно установить из App Store прямо на Mac. Они запускаются в окне, работают через Rosetta 2 или нативно (ARM64). Удобно, если привыкли к мобильному интерфейсу.

02

Почему нативная версия удобнее

Нативный macOS-клиент поддерживает TUN-режим, системное расширение, интеграцию с меню-баром и автоматический запуск при старте системы. Мобильная версия в окне — это компромисс: нет системного VPN, только прокси внутри приложения.

03

Intel-маки

На MacBook и iMac с Intel-процессором iPhone-приложения недоступны — только нативные macOS-версии клиентов. INCY, Happ и V2rayU работают одинаково хорошо на всех Mac с macOS 12 и выше.

важно · macos-специфика

Три момента, которые стоит знать про macOS

Системные расширения, TUN-режим и Gatekeeper — то, что отличает macOS от мобильных платформ и что нужно понимать, чтобы всё работало стабильно.

⚠ SYSTEM EXTENSION

Разрешите системное VPN-расширение

macOS требует явного разрешения на установку системного расширения для VPN-клиента. Без него клиент не сможет создать туннель. Разрешение запрашивается один раз — потребуется пароль администратора или Touch ID.

  • Системные настройки → Конфиденциальность и безопасность
  • Нажмите «Разрешить» рядом с именем клиента
  • После разрешения окно больше не появится
ℹ TUN VS ПРОКСИ

Включайте TUN-режим для полного покрытия

TUN-режим (или «Full Tunnel») пропускает через VPN весь трафик системы — браузер, приложения, обновления. Без TUN работает только прокси-режим: VPN видит только трафик клиента или браузера с настройками прокси.

  • В INCY: настройки → «TUN Mode» → включить
  • В Happ: «Full Tunnel» → включить
  • В V2rayU: «System Proxy» → off, «TUN» → on
✓ GATEKEEPER

Если macOS блокирует запуск клиента

Для клиентов, установленных не из App Store (V2rayU), macOS может показать «Невозможно открыть, так как разработчик не проверен». Это нормально — разрешите запуск через Системные настройки.

  • Правый клик по приложению → «Открыть»
  • Или: Системные настройки → Конфиденциальность и безопасность → «Разрешить»
  • Скачивайте .dmg только с официального сайта клиента
