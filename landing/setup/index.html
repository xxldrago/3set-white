04 · если что-то пошло не так

Частые проблемы и решения

Собрали самые частые проблемы, с которыми сталкиваются пользователи при настройке. Если вашей проблемы нет в списке — напишите в поддержку.

⚠ VPN НЕ ПОДКЛЮЧАЕТСЯ

Клиент не может установить соединение

Проверьте: (1) ключ подписки актуален — обновите подписку в клиенте, (2) брандмауэр не блокирует клиент — разрешите сетевой доступ, (3) попробуйте другой сервер из той же локации.

РЕШЕНИЕ: ОБНОВИТЬ ПОДПИСКУ В КЛИЕНТЕ → ВЫБРАТЬ ДРУГОЙ СЕРВЕР → ПЕРЕЗАПУСТИТЬ КЛИЕНТ
ℹ SAFARI НЕ ОТКРЫВАЕТ КЛИЕНТ НА iOS

Кнопка «Добавить в приложение» не работает

На iOS импорт подписки работает только через Safari. Chrome, Яндекс и другие браузеры не могут передать deep-link в приложение из-за ограничений системы.

РЕШЕНИЕ: ОТКРЫТЬ PANEL.3SET.ONLINE ИМЕННО В SAFARI → ОЧИСТИТЬ КЕШ SAFARI → ПОВТОРИТЬ
⚠ VPN ОТКЛЮЧАЕТСЯ В ФОНЕ

На Android соединение обрывается, когда экран выключен

Android агрессивно «убивает» фоновые приложения для экономии батареи. Нужно отключить экономию батареи для клиента и добавить его в автозагрузку.

РЕШЕНИЕ: НАСТРОЙКИ → ПРИЛОЖЕНИЯ → INCY/HAPP → БАТАРЕЯ → «БЕЗ ОГРАНИЧЕНИЙ»
ℹ SYSTEM EXTENSION НА MACOS

macOS блокирует запуск клиента или TUN-адаптер

Для клиентов, установленных не из App Store, macOS может показать «Невозможно открыть, так как разработчик не проверен». Это работа Gatekeeper — разрешите запуск через Системные настройки.

РЕШЕНИЕ: ПРАВЫЙ КЛИК ПО ПРИЛОЖЕНИЮ → «ОТКРЫТЬ» · ИЛИ: СИСТЕМНЫЕ НАСТРОЙКИ → КОНФИДЕНЦИАЛЬНОСТЬ → «РАЗРЕШИТЬ»
⚠ TUN-РЕЖИМ НЕ ВКЛЮЧАЕТСЯ

На Windows или macOS TUN не поднимается

TUN-режим требует прав администратора для создания виртуального сетевого адаптера. Также антивирус (Касперский, ESET, Avast) может блокировать создание адаптера.

РЕШЕНИЕ: ЗАПУСТИТЬ КЛИЕНТ ОТ ИМЕНИ АДМИНИСТРАТОРА · ДОБАВИТЬ КЛИЕНТ В ИСКЛЮЧЕНИЯ АНТИВИРУСА
ℹ QR-КОД НЕ СКАНИРУЕТСЯ НА TV

Не получается передать подписку на Smart TV

Если QR-код не сканируется или камера телефона сломана — используйте код привязки (4–6 символов). Введите его на panel.3set.online, и подписка привяжется к телевизору.

РЕШЕНИЕ: НА TV ПОЯВИТСЯ КОД → ВВЕСТИ ЕГО НА PANEL.3SET.ONLINE → ПОДПИСКА ПРИВЯЖЕТСЯ АВТОМАТИЧЕСКИ
⚠ РОУТЕР НЕ ТЯНЕТ VPN

После настройки на OpenWrt скорость упала, пинг вырос

VPN-клиент + геобазы + буферизация съедают ресурсы. Проверьте загрузку CPU и ОЗУ через top. Если роутер слабый — упростите правила PBR или перейдите на более лёгкий клиент.

РЕШЕНИЕ: ПРОВЕРИТЬ CPU ЧЕРЕЗ TOP · ОБНОВИТЬ ГЕОБАЗЫ · УПРОСТИТЬ ПРАВИЛА МАРШРУТИЗАЦИИ
✓ САЙТЫ НЕ ОТКРЫВАЮТСЯ ПОСЛЕ ПОДКЛЮЧЕНИЯ

VPN подключён, но заблокированные сайты всё равно не работают

Возможно, в клиенте включён режим «System Proxy» вместо «TUN». System Proxy работает только с браузерами и «умными» приложениями — Discord, Steam, игры его игнорируют.

РЕШЕНИЕ: ВКЛЮЧИТЬ TUN MODE В КЛИЕНТЕ · ПРОВЕРИТЬ IP ЧЕРЕЗ 2IP.RU · ПЕРЕЗАПУСТИТЬ БРАУЗЕР
