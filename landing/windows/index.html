Шаг 3. Установите приложение и разрешите брандмауэр

Запустите скачанный установщик (.exe или .msi). При первом запуске Windows может запросить разрешение брандмауэра на сетевой доступ — обязательно разрешите для всех сетей.

Запустите установщик

Откройте скачанный файл (FlClashX-Setup.exe, Happ-Setup.exe или INCY-Setup.exe). Следуйте стандартному мастеру установки: «Далее» → «Установить» → «Готово». При желании добавьте клиент в автозагрузку — это удобно, чтобы VPN поднимался сразу после старта Windows.

04

Разрешите запуск в брандмауэре Windows

При первом запуске клиента Windows Defender Firewall покажет окно: «Разрешить приложению связываться с сетью». Выберите «Разрешить для всех сетей» (частные и публичные). Если окно пропустили — откройте «Брандмауэр Windows → Разрешённые приложения» и добавьте клиент вручную. Без этого разрешения TUN-режим не поднимется.

tun vs system proxy · важно

TUN или System Proxy — в чём разница?

На Windows есть два режима работы VPN. Для большинства программ нужен TUN — он пропускает через VPN весь трафик системы. System Proxy подходит только приложениям, которые его учитывают.

✓ РЕКОМЕНДУЕМ

TUN-режим (Full Tunnel)

Создаёт виртуальный сетевой адаптер и пропускает через VPN весь трафик системы — браузер, мессенджеры, игры, обновления, торренты. Работает для всех программ без исключения.

  • Полное покрытие: все приложения в VPN
  • Защита от утечек DNS и IP
  • Работает с играми и торрентами
  • Требует прав администратора при первом включении
  • Включите в настройках клиента: «TUN Mode» → ON
ℹ ОГРАНИЧЕННЫЙ РЕЖИМ

System Proxy (системный прокси)

Настраивает системные прокси-настройки Windows. Через VPN идёт только трафик программ, которые учитывают эти настройки — в основном браузеры и некоторые мессенджеры.

  • Работает только с браузерами и «умными» приложениями
  • Игры, торренты, Discord, Steam — часто НЕ видят прокси
  • Возможны утечки DNS при неправильной настройке
  • Не требует прав администратора
  • Подходит, если TUN по какой-то причине недоступен
05 · подключение

Шаг 5. Выберите сервер и проверьте сайты

Включите TUN-режим, выберите ближайший сервер и нажмите «Подключиться». После этого откройте браузер и проверьте, что заблокированные сайты работают.

08

Включите TUN-режим

В настройках клиента найдите переключатель «TUN Mode» (или «System TUN») и включите его. При первом включении Windows запросит права администратора — подтвердите. После этого в системном трее появится иконка VPN-адаптера.

TUN MODE · ON ADMIN RIGHTS · ONE-TIME VIRTUAL ADAPTER
09

Выберите сервер

В списке серверов выберите ближайший — он даст минимальный пинг. Из России лучше всего работают Финляндия (22 мс), Германия (34 мс), Нидерланды (38 мс) и Турция (45 мс). Если один сервер не отвечает — переключитесь на другой из той же локации.

10

Проверьте открытие сайтов

Нажмите «Подключиться» в клиенте. После установки соединения откройте браузер и проверьте сайты, которые раньше не работали: Instagram, YouTube, LinkedIn, Discord. Если что-то не открывается — попробуйте другой сервер или обновите подписку.

Три момента, которые стоит знать про Windows

Брандмауэр, TUN-режим и антивирусы — то, что отличает Windows от мобильных платформ и что нужно понимать, чтобы всё работало стабильно.

⚠ БРАНДМАУЭР

Разрешите клиенту сетевой доступ

Windows Defender Firewall по умолчанию блокирует сетевую активность новых приложений. Если клиент не может подключиться или TUN-режим не поднимается — дело почти наверняка в брандмауэре.

  • Параметры → Конфиденциальность и безопасность → Брандмауэр
  • «Разрешённые приложения» → добавьте клиент
  • Отметьте галочки «Частные» и «Публичные» сети
ℹ TUN VS PROXY

Для большинства программ нужен TUN

System Proxy работает только с браузерами и приложениями, которые учитывают системные прокси-настройки. Игры, Discord, Steam, торренты и многие мессенджеры через System Proxy не идут — только через TUN.

  • TUN — весь трафик системы через VPN
  • System Proxy — только «умные» приложения
  • Для полной приватности всегда включайте TUN
✓ АНТИВИРУСЫ

Если антивирус блокирует TUN-адаптер

Некоторые антивирусы (Касперский, ESET, Avast) могут блокировать создание виртуального сетевого адаптера для TUN-режима. Если TUN не включается — добавьте клиент в исключения антивируса.

  • Добавьте папку клиента в исключения антивируса
  • Разрешите создание TUN-адаптера (Wintun / tun2socks)
  • Если проблема осталась — попробуйте System Proxy как временное решение
